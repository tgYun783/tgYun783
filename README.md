## 🚀 Key Projects
### 🏆 CSForces (한국형 알고리즘 대회 플랫폼)
* **기간:** 2026.01.02 ~ 2026.01.22
* **역할:** 백엔드 API 설계 및 핵심 비즈니스 로직 구현
* **Tech:** `Django`, `DRF`, `SQLite`
* **요약:** 심야 시간대에 집중된 글로벌 플랫폼(Codeforces)의 접근성 한계를 극복하기 위해 기획된 로컬 대회 운영 시스템. 외부 API 연동 파이프라인 구축 및 동적 ELO 레이팅 산출 알고리즘 설계. Notion 기반의 칸반 보드 및 정기 스크럼을 도입하여 개발 병목을 해결하고 팀 협업 효율을 극대화함.
